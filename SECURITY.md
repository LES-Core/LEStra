# Security policy

LEStra is pre-release and does not yet implement secure networking.
Do **not** rely on it for confidentiality, anonymity or VPN protection.

Please avoid publicly disclosing an exploitable security issue before maintainers
have an opportunity to respond. Use GitHub's private vulnerability reporting
feature if it is enabled for the repository. Otherwise contact the maintainers
privately through an official LES Core contact channel.

No security response SLA is promised at this stage.
