# Contributing

Thank you for considering a contribution to LEStra.

- Use English for source comments, documentation and pull requests.
- Run `cargo fmt --all`, Clippy and tests before submitting a PR.
- Use Conventional Commits **without scope**: `type: short English description`.
  Examples: `chore: initialize Rust workspace`, `test: add protocol codec tests`.
- Open an issue or design discussion before changing wire format or crypto architecture.
- Do not introduce custom cryptographic primitives.

Unless explicitly stated otherwise, contributions intentionally submitted for inclusion
in LEStra are licensed under MIT OR Apache-2.0, without additional terms or conditions.
